RUNNING LOCALLY
--------------------------------------------------------------------------------
- Create venv; pip install -r requirements.txt
- Set GROQ_API_KEY in ai_10022300177/.streamlit/secrets.toml or environment
- From repo root (parent of ai_10022300177 if nested): run Streamlit pointing
  at app.py so relative paths data/ and logs/ match vector_store defaults.
- First run: index build can take several minutes (model + embedding).

--------------------------------------------------------------------------------
REBUILDING THE INDEX
--------------------------------------------------------------------------------
- UI: sidebar "Rebuild Index" clears st.cache_resource and reruns.
- Manual: delete data/faiss.index and data/metadata.json, then restart app.
- Changing PDF source or chunk strategy requires rebuild for full consistency.

--------------------------------------------------------------------------------
PDF SOURCE OVERRIDES
--------------------------------------------------------------------------------
- Environment variable SOURCE_PDF_PATH can point to any readable PDF path.
- If unset, code may use a configured LOCAL_PDF_PATH in data_loader.py when
  present on disk; otherwise falls back to the remote budget PDF URL.
- For team machines or deployment, prefer SOURCE_PDF_PATH and avoid hardcoded
  user-specific paths in shared branches.
